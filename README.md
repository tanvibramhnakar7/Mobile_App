📱 Mobile Price Range Classification App

This Streamlit web app predicts the mobile price range (0 - 3) based on various smartphone features such as RAM, battery power, screen size, and more.
It uses a machine learning model trained on a mobile price dataset and the best-performing model is loaded from a .pkl file.

🧠 Project Overview

The goal of this project is to classify mobile phones into one of four price categories:

Class	Description
0	Low Cost 💸
1	Medium Cost 💰
2	High Cost 💎
3	Very High Cost 🚀

Users can input various features, and the model will predict which price category the mobile belongs to.
